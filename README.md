# Ecosystem Showdown

A gamified revision quiz for Form 2 Science (Ecosystems: food chains, food webs and interactions between organisms).

Built as a prototype for HPGD3203 Emerging Technologies for Teaching and Learning.

Features: 12 illustrated questions, instant explanation feedback, Practice and Challenge modes, lifelines (50:50, Hint, +15s), streaks, bonus round, Second Chance round, read-aloud, leaderboard and a teacher results view.
